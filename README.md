## 📖 About

**Planet Survivor** is a personal game-development project that explores what Flutter can do beyond traditional app development. It combines an interactive 3D world, a fully animated character, a movement system and survival gameplay in a single cross-platform codebase.

The goal is simple: prove that a real-time 3D game can be built with Flutter.

## ✨ Features

| | Feature | Description |
|---|---|---|
| 🌍 | **Alien-planet world** | An immersive 3D environment to explore |
| 🧍 | **Animated character** | A rigged 3D character with 212 embedded animations |
| 🏃 | **Fluid movement** | Walking, running, jumping, crouching and dodging |
| 📷 | **Orbit camera** | Rotate around the character and zoom in or out |
| 🪙 | **Coin collection** | Find and collect coins around the map |
| ❤️ | **Survival mechanics** | A health system that keeps the pressure on |
| 📱 | **Touch and keyboard** | On-screen controls for mobile, keys for desktop |

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| [Flutter](https://flutter.dev) and Dart | Cross-platform framework and game logic |
| [flutter_scene](https://pub.dev/packages/flutter_scene) | 3D rendering and scene management |

## 🚀 Getting Started

### Prerequisites

- A recent [Flutter SDK](https://docs.flutter.dev/get-started/install)
- **Impeller** enabled (`flutter_scene` relies on Flutter GPU)
- A device or emulator that supports Impeller

> `flutter_scene` is an experimental package. Requirements can change between versions, so check its [documentation](https://pub.dev/packages/flutter_scene) if the build fails.
